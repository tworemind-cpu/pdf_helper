# 📥 다운로드 및 실행 방법

[← README로 돌아가기](../README.md)

## 1. 다운로드

**[👉 최신 pdf_helper.exe 다운로드 (Releases)](https://github.com/tworemind-cpu/pdf_helper/releases/latest)**

1. 위 링크를 눌러 Releases 페이지로 이동합니다.
2. **Assets** 목록에서 최신 `pdf_helper.exe` 를 내려받습니다.

## 2. 실행

1. 내려받은 `pdf_helper.exe` 를 **더블클릭**하면 바로 실행됩니다. (별도 설치 필요 없음)
2. 처음 실행할 때 **"Windows의 PC 보호"** 경고창이 뜨면 다음 순서로 진행해 주세요.
   1. 경고창에서 **추가 정보** 를 클릭합니다.
   2. 새로 나타난 **실행** 버튼을 클릭합니다.

> ⚠️ 서명되지 않은 개인 제작 프로그램이라 처음 실행 시 경고가 나올 수 있으며, 위 순서대로 진행하면 정상적으로 실행됩니다.

## 3. 사용 환경

- **Windows 10 / 11** (64비트)
- 한글·엑셀·워드·파워포인트 파일을 PDF로 변환하려면 해당 프로그램이 PC에 설치되어 있어야 합니다. 자세한 내용은 [README의 사용 환경](../README.md#-사용-환경)을 참고해 주세요.
